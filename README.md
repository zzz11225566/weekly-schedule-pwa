# 七日课表

一个面向大学生的七日日程 PWA。周一到周五使用固定课程时间格，可编辑“有课/无课”，支持课前与课后临时待办；周六日按时间轴自动摆放活动。数据只保存在本机浏览器，不需要账号。

## 本地运行

```powershell
npm start
```

浏览器打开 `http://localhost:4173`。

## 安装到 iPhone

1. 先在 Safari 打开部署后的 HTTPS 地址。
2. 点击底部“分享”按钮。
3. 选择“添加到主屏幕”。
4. 点“添加”。

安装后会像普通 App 一样从主屏幕启动，并支持离线打开。

## 数据说明

- 日程和设置保存在浏览器的 `localStorage`。
- 清除 Safari 网站数据会同时清除本机日程，建议偶尔截图备份。
